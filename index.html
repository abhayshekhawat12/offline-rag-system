🔒 100% Offline & Private AI

Private Local Offline RAG

A multimodal Retrieval-Augmented Generation dashboard supporting PDFs, Text files, and Images powered by local Llama-3 & LLaVA.

🚀 Key Features

🧠 Offline LLM

Powered by local Ollama (Llama-3 8B) for ultra-fast and private Q&A.

🖼️ Multimodal Vision

Integrated LLaVA model to read scanned PDFs and analyze images.

⚡ Chroma Vector DB

High performance document indexing using MiniLM-L6 embeddings.

📝 Auto Study Guide

1-Click comprehensive Question & Answer generation from uploads.

💻 Local Execution Guide

This application is designed to run securely on your local environment without any cloud data leaks.

  1. Install Dependencies:
    pip install -r requirements.txt
  2. Start Ollama & Pull Models:
    ollama pull llama3
    ollama pull llava
  3. Launch Streamlit Dashboard:
    streamlit run app.py
🌐 Local URL: http://localhost:8502
